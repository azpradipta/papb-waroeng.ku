Kebijakan privasi Waroeng.Ku

Kebijakan ini menjelaskan penggunaan data dalam aplikasi kasir Waroeng.Ku serta cara menghubungi pengelola dan meminta penghapusan.

Data yang digunakan

Waroeng.Ku menggunakan nama, email, dan informasi akun untuk pendaftaran serta login. Password diproses oleh layanan autentikasi Supabase. Data toko meliputi nama, alamat dan telepon jika diisi, akun Kasir, produk, harga, stok, serta riwayat transaksi tunai.

Aplikasi tidak meminta data kartu pembayaran, lokasi perangkat, kontak, kamera, atau mikrofon.

Tujuan dan penyimpanan

Data dikirim melalui internet ke layanan Supabase untuk autentikasi dan penyimpanan database. Data digunakan untuk mengelola warung, mengatur akses Pemilik dan Kasir, memproses penjualan, serta membuat laporan dan nota.

Aplikasi menyimpan sesi login pada perangkat agar pengguna tidak perlu masuk setiap kali membuka aplikasi. Keluar dari akun menghapus sesi login lokal. Halaman permintaan penghapusan di situs ini menyimpan token login hanya dalam memori halaman dan tidak menyimpannya dalam cookie atau penyimpanan browser.

Supabase juga dapat mencatat alamat IP, user agent, waktu, dan aktivitas login untuk keamanan serta operasional layanan.

Siapa yang dapat mengakses

Pemilik dapat mengelola data tokonya dan akun Kasir. Kasir mendapat akses sesuai perannya. Pengelola aplikasi dan penyedia layanan dapat memproses data untuk menjalankan layanan dan menangani gangguan.

Waroeng.Ku tidak memasang iklan atau SDK analitik. Jika pengguna membagikan PDF, data dalam dokumen dikirim ke penerima atau aplikasi yang dipilih pengguna.

Penyimpanan dan penghapusan

Data akun dan toko disimpan selama digunakan untuk layanan. Pengguna dapat mengajukan penghapusan melalui Pengaturan → Hapus Akun dan Data di aplikasi atau melalui halaman permintaan penghapusan ini.

Pengiriman permintaan belum langsung menghapus akun. Pengelola meninjau identitas dan dampaknya, kemudian memproses permintaan paling lambat 30 hari kalender setelah verifikasi identitas yang diperlukan selesai.

  • Pemilik: penghapusan mencakup akun Pemilik, seluruh data tokonya, produk, stok, transaksi, laporan, dan semua akun Kasir yang terkait. Simpan dokumen yang masih dibutuhkan dan beri tahu Kasir sebelum mengajukan permintaan.
  • Kasir: penghapusan mencakup akun dan data pribadinya. Catatan penjualan toko dipertahankan untuk Pemilik dengan identitas Kasir dilepas dan nama diganti menjadi “Kasir dihapus”.

Salinan cadangan dan log teknis dapat tetap tersimpan sampai masa retensi layanan atau konfigurasi pengelola berakhir; penghapusan tidak membuat semua salinan tersebut langsung hilang.

Catatan penyelesaian permintaan dapat disimpan tanpa hubungan ke akun untuk membuktikan pemrosesan. Dokumen PDF yang telah dibagikan atau disimpan pada perangkat penerima tidak ikut terhapus dari perangkat tersebut.
